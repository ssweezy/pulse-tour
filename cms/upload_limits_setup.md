# Настройка загрузки файлов в PayloadCMS

## Конфигурация загрузки

В PayloadCMS вы можете настроить параметры загрузки файлов в коллекции Media:

```typescript
export const Media: CollectionConfig = {
  slug: 'media',
  access: {
    read: () => true,
  },
  fields: [
    {
      name: 'alt',
      type: 'text',
      required: true,
    },
  ],
  upload: {
    staticDir: path.resolve(dirname, 'media'), // Путь к директории для хранения файлов
    mimeTypes: ['image/*'], // Разрешенные типы файлов
    adminThumbnail: 'url', // Как отображать миниатюры в админке
    imageSizes: [
      // Настройка размеров изображений
      {
        name: 'webp',
        width: 1920,
        height: 1080,
        format: 'webp',
        position: 'center',
      },
    ],
  },
}
```

## Решение проблемы с отсутствующими файлами

1. Убедитесь, что директория `cms/media` существует
2. Проверьте, что в базе данных не сохранены ссылки на файлы, которые были удалены с диска
3. При миграции данных из другой системы убедитесь, что файлы также были перемещены

## Особенности продакшен-окружения

На продакшен-сервере директория для хранения медиафайлов отличается от локальной разработки:

- **Локально**: `../../media` (относительно файла конфигурации)
- **На сервере**: `/var/www/payload-cms/media` (абсолютный путь)

## Управление файлами

- Файлы загружаются в директорию, указанную в настройках коллекции Media
- При загрузке изображений автоматически создаются различные размеры для оптимизации
- При удалении записи из коллекции Media, файлы остаются на диске
- При очистке базы данных, убедитесь, что очищаете и директорию с файлами

## Оптимизация изображений

Payload CMS автоматически оптимизирует загружаемые изображения:

- Конвертация в формат WebP для уменьшения размера файлов
- Создание нескольких размеров изображений (thumbnail, small, medium, large)
- Сжатие с качеством 80% для баланса между качеством и размером
- Сохранение оригинального изображения и оптимизированных версий

## Важное замечание по оптимизации изображений

В текущей версии оптимизация изображений временно отключена, так как требует выполнения миграции базы данных для добавления соответствующих колонок.

Для включения оптимизации изображений в будущем:

1. Создайте миграцию с помощью команды `pnpm payload migrate:create add-image-sizes`
2. Добавьте в миграцию обновление схемы коллекции Media
3. Выполните миграцию с помощью `pnpm payload migrate`

## Возможные решения ошибки "File ... is missing on the disk"

1. Проверьте, что все файлы, на которые есть ссылки в базе данных, существуют в директории, указанной в настройках
2. Удалите записи из базы данных, которые ссылаются на несуществующие файлы
3. Восстановите недостающие файлы в директории
