# Инструкция по обновлению зависимостей и решению проблемы с оптимизацией изображений

## Проблема

Ошибка несовместимости версий пакетов Payload CMS:

```
Mismatching "payload" dependency versions found: @payloadcms/db-postgres@3.68.5 (Please change this to 3.68.2). All "payload" packages must have the same version.
```

А также проблема с миграцией базы данных, связанная с попыткой пересоздания уже существующих таблиц.

## Решение

Для устранения проблемы на сервере выполните следующие шаги:

### Шаг 1: Обновите package.json

1. Откройте файл `package.json` на сервере
2. Убедитесь, что все пакеты Payload имеют одинаковую версию (3.68.2):

```json
{
  "dependencies": {
    "@payloadcms/db-postgres": "3.68.2",
    "@payloadcms/next": "3.68.2",
    "@payloadcms/richtext-lexical": "3.68.2",
    "@payloadcms/ui": "3.68.2",
    "payload": "3.68.2",
    ...
  }
}
```

### Шаг 2: Обновите зависимости

Выполните следующие команды на сервере:

```bash
# Перейдите в директорию cms
cd /var/www/payload-cms/  # или wherever your cms is installed

# Удалите node_modules и pnpm-lock.yaml
rm -rf node_modules
rm -f pnpm-lock.yaml

# Установите зависимости
pnpm install
```

### Шаг 3: Альтернативное решение для оптимизации изображений

Вместо выполнения миграции (которая может привести к конфликту с существующей схемой),
рекомендуется включить оптимизацию изображений через обновление схемы без миграции:

1. Временно оставьте конфигурацию Media без оптимизации изображений (как в текущем состоянии)
2. Для включения оптимизацию изображений в будущем:
   - Обновите схему коллекции Media, добавив настройки imageSizes
   - Запустите приложение в dev режиме: `pnpm payload dev` - это автоматически обновит схему
   - После проверки работоспособности перезапустите в production режиме

### Шаг 4: Перезапустите приложение

```bash
pm2 restart payload-cms
```

## Важно

- Все пакеты Payload CMS должны иметь одинаковую версию
- Миграция может быть сложной в существующей системе с данными
- Рекомендуется создать резервную копию базы данных перед любыми изменениями
- Оптимизация изображений может быть включена через обновление схемы в dev режиме
